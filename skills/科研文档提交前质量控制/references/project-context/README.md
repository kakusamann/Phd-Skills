# 项目上下文规则

本目录用于保留特定项目、课题或子任务的背景约定，例如正式名称、职责边界、固定术语和任务书专属要求。

这些内容**不属于通用核心检查规则**，不得默认套用到其他项目。

## 加载条件
只有在以下情况之一成立时才加载：
- 用户明确指定对应项目或项目 Profile；
- 当前文档清楚表明属于该项目，且用户已授权沿用该项目背景；
- 用户明确要求核对项目任务书、职责边界或项目专属术语。

如果无法确认项目归属，不加载，也不要求用户先配置项目上下文。

项目 Profile 可以补充检查依据，但不能改变主 Skill 的只读原则，也不能将项目任务书核对强制加入每次全面检查。
