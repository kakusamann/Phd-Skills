# 05 文本与语言质量

默认优先级：P1

本模块检查文字层面的明确错误和影响理解的表达问题。默认采用中立、克制的语言质量标准，不主动套用特定论文、报告或期刊风格。

## 检查项目

### 文字准确性
- 错别字、漏字、多字、重复字和明显输入错误。
- 词语搭配错误、语法成分残缺、指代不明和明显歧义。
- 同一句或相邻句中出现无意义的重复表达。
- 句子成分关系不清，导致读者难以理解主语、动作或对象。

### 标点与空格
- 中英文标点误用、重复标点、括号或引号不配对。
- 中文与英文、数字、单位、缩写之间的空格使用不一致。
- 斜杠、加号、连字符等符号在普通中文表达中使用不当。
- 列表、标题、图表题等位置的标点形式不一致。

### 术语与缩写
- 同一专业概念是否存在多种写法。
- 缩写首次出现时是否需要定义，是否存在全称与缩写不对应。
- 中英文术语是否存在明显错配。
- 专有名称、机构名称、产品名称和技术名称是否前后统一。

### 表达清晰度
- 句子是否存在明显歧义或逻辑关系不清。
- 是否有不必要的口语化表达、冗余修饰或空泛措辞。
- 是否出现过长且层次不清的句子。
- 是否存在缺少明确指代对象的“该方法”“上述结果”“其”等表达。

## 默认中立原则

除非用户主动指定写作风格或提供正式范文/规范：
- 不强制将普通表达改成学术表达。
- 不强制使用某种固定句式、段落结构或连接词。
- 不为追求“正式”而替换准确、自然的原有措辞。
- 不把个人偏好的表达方式当成错误。
- 不主动进行整段润色或全文改写。

如果用户明确指定语言风格，才加载对应的写作风格 Profile，并仅检查其明确规定的特征。

## 问题判断

错别字、明显语法错误、标点错误通常可列为 P0；表达不够简洁、措辞可优化等通常列为 P1。应结合语境判断，不机械套用。

## 证据与报告

提供原句和位置。修改建议应尽量局部、具体，不重写整段，也不得改变科研含义、数据、限定条件或作者意图。
