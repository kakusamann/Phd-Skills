# 07 复制与编辑痕迹检查

默认优先级：P0

本模块检查文档在复制、合并、反复编辑和版本整理过程中可能遗留的问题。只描述可观察到的异常，不在没有证据时断言内容一定来自复制粘贴。

## 检查项目

### 格式与样式污染
- 正文中突然出现与相邻同类段落明显不同的字体、字号、颜色、行距、缩进或段落间距。
- 同一标题层级或同一类图表题中出现孤立的格式异常。
- 粘贴后保留了不属于当前文档的项目符号、编号、底纹、边框、超链接或字体颜色。
- 局部文字存在异常字符、不可见空格、软回车或不合理的换行。
- 表格单元格、文本框、脚注或页眉页脚中出现与正文不协调的格式。

### 内容残留
- 出现其他项目、课题、机构、作者、产品或研究对象的名称，且与当前文档主题不符。
- 出现旧版本标题、旧编号、旧日期、旧年度、旧图表引用或过时的文件名称。
- 出现“XXX”“待补充”“此处插入”“TODO”“TBD”等占位符。
- 出现与上下文无关的句子、段落、图题、表题或参考说明。
- 同一段落或大段文本重复出现，且没有合理的重复用途。
- 存在前后版本拼接导致的内容断裂、重复或相互矛盾。

### 修订与隐藏信息
在工具能力允许时，检查：
- 未接受或未拒绝的修订记录。
- 未删除的批注和审阅意见。
- 隐藏文字、隐藏段落或异常字体效果。
- 页眉、页脚、文本框、脚注、尾注中的遗留内容。
- 文档属性、作者信息或模板残留（仅当用户要求检查或其确实影响提交时）。

### 编辑结构异常
- 空白页、孤立标题、异常分页符或分节符。
- 图片、表格或文本框被遗留在错误位置。
- 交叉引用、域代码或自动编号显示为错误文本。
- 内容被遮挡、裁切或意外隐藏。

## 判断原则

- 格式差异必须先排除标题、引用、图注、代码、公式、表格等正常特殊格式。
- 只有在当前文档语境中明显不相关时，才把其他项目名称列为疑似残留。
- 相同段落重复可能是必要内容，必须检查上下文后再报告。
- 无法访问 DOCX 修订记录、批注或隐藏文字时，应在检查范围说明中标记未检查，不得声称已经排除。
- 不根据文风变化推断内容来源。

## 证据与报告

尽量定位到页码、章节、段落、表格或文档结构对象。说明具体异常，例如“第 4 页该段使用蓝色 10.5 磅字体，而相邻正文均为黑色 12 磅；该段不属于引用或图注”。

对同类问题可合并呈现，但要列出所有位置和发生次数。
