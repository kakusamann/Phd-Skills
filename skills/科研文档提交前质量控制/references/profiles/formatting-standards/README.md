# 排版与提交规范

本目录存放有明确来源的格式规范，例如学校论文模板、期刊投稿指南、机构或组织的科技报告模板和用户自定义 Word 规范。

## 加载规则

- 只有用户提供、明确指定或确认适用的规范才作为硬性检查依据。
- 没有规范时，以文档自身稳定的格式为基准，检查明显不一致和排版异常。
- 页面尺寸、页边距、页面方向等不属于默认检查项；只有规范或用户要求明确涉及这些项目时才检查。
- 不得根据某一篇旧文档推断所有新文档都必须使用相同格式。
- 规范文件为空、缺失或不可读取时，跳过该规则，继续核心检查。

新增规范请使用同目录下的 _template.md，并保留规范名称、版本和来源。
