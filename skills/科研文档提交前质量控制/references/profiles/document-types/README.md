# 文档类型规则

本目录存放不同文档类型的结构和编号规则，例如科技报告、学术论文、学位论文、项目申请书和项目验收材料。

文档类型 Profile 主要解决章节组织、标题层级、图表/公式编号、附录结构和文内交叉引用的差异。它不应自动扩展成内容创作或实质性学术审稿任务。

## 加载规则

- 文档类型清晰且存在对应 Profile 时，可以加载。
- 没有对应 Profile 时，按文档自身稳定的结构和编号模式检查。
- 不得因为缺少某种文档类型 Profile 而停止检查。
- 不得仅凭文档类型名称推断特定学校、期刊或项目的硬性格式要求。
- 用户提供的正式模板或指南优先于本目录中的通用 Profile。

## Profile 应包含

- 适用文档类型与排除范围；
- 规则来源及版本；
- 标题层级和章节组织要求；
- 章节、图、表、公式、附录编号规则；
- 图题和表题位置要求；
- 目录和交叉引用规则；
- 明确不检查的事项；
- 存在差异或例外时的处理方法。

新增规则请使用同目录下的 _template.md。
