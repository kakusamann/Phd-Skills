# 写作风格规则

本目录存放用户主动选择的语言风格规则，例如中文学术风格、英文 SCI 论文风格、科技报告风格或项目管理材料风格。

## 默认行为

**默认不加载任何风格化模板。** 主 Skill 采用中立的语言质量检查，只识别错别字、语法、歧义、冗余和明显不自然的表达，不强制改写成某种固定文风。

只有用户明确提出“按某某风格检查”或明确提供范文/规范时，才加载相应风格 Profile。

## 规则编写要求

- 描述可观察的句式、措辞、语气和表达要求。
- 尽可能提供正例、反例和适用边界。
- 不要只列“高级、专业、严谨、自然”等抽象形容词。
- 不把个人偏好写成普遍学术规范。
- 风格检查只用于提出问题和建议，不自动润色或重写文档。

新增风格规则请使用同目录下的 _template.md。
