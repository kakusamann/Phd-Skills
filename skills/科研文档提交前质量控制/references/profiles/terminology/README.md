# 专业术语库

本目录存放用户维护的专业术语、缩写、英文名称、推荐译法和禁用写法，例如环境科学与工程、生命周期评价、碳足迹、半导体制造等领域。

## 加载与缺省行为

- 用户指定术语库时，加载对应文件。
- 没有术语库、文件为空或无法读取时，主 Skill 必须继续运行，不得报错退出或要求用户先建立术语库。
- 没有外部术语库时，可以从当前文档自动提取临时术语表，检查同一文档内部的写法一致性。
- 自动提取的术语不代表其专业定义、译法或拼写一定正确，不得把它当作权威词典。
- 只有存在明确来源的推荐写法时，才可据此判定某个变体为错误；否则报告“存在多种写法，需确认”。

## 建议字段

| 字段 | 含义 |
|---|---|
| 中文术语 | 推荐中文写法 |
| 英文术语 | 对应英文全称 |
| 缩写 | 推荐缩写 |
| 允许变体 | 可以接受的其他写法 |
| 禁用写法 | 明确不应使用的写法 |
| 定义/说明 | 简短定义或使用边界 |
| 来源 | 标准、论文、任务书或用户确认 |
| 严格程度 | 强制/建议/仅供参考 |

新增术语请使用同目录下的 术语表模板.md。
